# SkyblockRU — русификатор Hypixel SkyBlock

Клиентский Fabric-мод: переводит на русский чат, описания предметов, меню,
боковую панель, надписи над хотбаром и реплики NPC. Подменяет текст прямо
при отрисовке — игру не меняет и преимуществ не даёт.

*Мод не связан с Hypixel Inc. и Mojang AB и не одобрен ими.*

---

> ## ⚠️ Мод в бета-тесте. Перевод неполный — и полным не будет
>
> **Вы обязательно встретите непереведённые описания, диалоги и надписи.**
> Это не поломка и не недосмотр, а свойство задачи:
>
> * текстов в SkyBlock десятки тысяч строк, и они добавляются быстрее,
>   чем переводятся;
> * Hypixel регулярно переписывает уже существующие — после обновления
>   часть строк снова показывается по-английски;
> * часть текста оставлена английской **намеренно** (см. таблицу ниже):
>   названия предметов, имена NPC, локации.
>
> Мод переводит то, что успел, и пополняется по мере игры: непереведённые
> строки уходят разработчику, а перевод возвращается **по сети, без
> переустановки**. Чем больше людей играет, тем быстрее закрываются дыры.
>
> Если что-то не переведено — так и задумано на этом этапе. Сообщать
> об этом не нужно, мод сам собирает такие строки.

## Установка

Скачайте архив под свою версию игры со страницы [Releases](../../releases),
распакуйте и откройте `КАК-УСТАНОВИТЬ.txt` — там расписан порядок для обычного
лаунчера Minecraft, MultiMC, Prism, Modrinth App, ATLauncher и CurseForge.

Внутри архива уже лежат сам мод и **подходящий Fabric API** — подбирать
ничего не нужно.

| Архив | Версии Minecraft | Java |
|---|---|---|
| `SkyblockRU-1.21.11.zip` | 1.21.11 | 21+ |
| `SkyblockRU-26.1.x.zip` | 26.1, 26.1.1, 26.1.2 | 25+ |
| `SkyblockRU-26.2.zip` | 26.2 | 25+ |

⚠️ **Hypixel пускает в SkyBlock только с версии 1.21.11 и новее.** На версиях
ниже сервер откажет в подключении — это его решение, а не поломка мода.

## Что переводится, а что нет

Часть текста остаётся английской намеренно — то, что игрок вводит в поиск
аукциона или сверяет с гайдом.

| Переводим | Оставляем как есть |
|---|---|
| описания предметов, чат, меню, подсказки | **названия предметов** — по ним ищут на аукционе |
| зачарования, реплики NPC, названия мобов | **имена NPC** (`Taylor`, `Jerry`) |
| материалы со строчной буквы (`gold ore`) | **названия локаций** (`Birch Park`) |
| характеристики, понятные из слова (Сила, Защита) | жаргон: `Mining Fortune`, `Magic Find`, `Pristine` |

⚠️ `Gems` (донат-валюта) и `Gemstones` (самоцветы с добычи) — разные вещи,
поэтому `Gems` не переводится: «Самоцветы» сделало бы их неразличимыми.

Полный перевод — включая названия предметов, зачарований и характеристики —
планируется отдельной работой. Сейчас его нет: мод переводит описания,
а названия оставляет английскими.

## Команды

| Команда | Что делает |
|---|---|
| `/skyblockru` | версия, состояние, счётчики |
| `/skyblockru on` / `off` | включить или выключить перевод |
| `/skyblockru update` | проверить обновление перевода |
| `/skyblockru telemetry on\|off` | отправка непереведённых строк |

Клавиши настраиваются в «Настройки → Управление»: **Shift** — справка по
термину, **Alt** — справка по зачарованию, **V** — показать оригинал.

## Обновление перевода

Словари обновляются **по сети, без переустановки мода**: при заходе на Hypixel
мод сверяет манифест и докачивает только изменившиеся файлы. Новый jar нужен,
только когда меняется код.

## Что отправляется разработчику

Мод отправляет **строки игрового интерфейса, которые не смог перевести** —
чтобы перевод пополнялся у всех сразу. В пакете ровно три вещи: версия мода,
версия игры и сами строки.

**Не отправляется никогда:** ник, UUID, имя профиля, координаты, адрес
сервера, чат игроков и личные сообщения. Реплики других игроков отсекаются
отдельным фильтром до отправки.

Отправка включена по умолчанию; при первом запуске мод один раз сообщает
об этом в чат. Выключается командой `/skyblockru telemetry off` — перевод
продолжает работать как обычно.

## Для разработчиков

### Сборка

```bash
gradlew build            # все поддерживаемые версии
python tools/release.py  # готовые jar в release/
python tools/pack.py     # архивы раздачи в release/packs/
```

Проект собирается через [Stonecutter](https://stonecutter.kikugie.dev/) —
одна кодовая база на несколько версий Minecraft. Список версий и то, каким
скриптом собирать каждую, лежит в `settings.gradle.kts`.

⚠️ У Fabric **два плагина Loom**: с 26.1 Minecraft необфусцирован и ремапить
нечего (`fabric-loom`), для 1.21.x нужен `fabric-loom-remap`. Отсюда два
build-скрипта.

### Устройство словарей

Словари — это JSON в `src/main/resources/assets/skyblockru/packs/`
(встроенные) и в `config/skyblockru/packs/` (пользовательские, перекрывают
встроенные).

```json
{
  "id": "мой-словарь",
  "priority": 20,
  "exact":      { "Auction House": "Аукцион" },
  "regex":      [ { "p": "^\\+([\\d,.]+) Coins$", "r": "+$1 монет" } ],
  "glossary":   { "Strength": "Сила" },
  "paragraphs": { "текст абзаца целиком": "перевод целиком" }
}
```

* **exact** — точное совпадение. `{n}` внутри — любое число, `{s}` — ник.
* **regex** — регулярные выражения, `$1` — группы. Поле `tg` переводит
  захваченные куски по словарю.
* **glossary** — подмена терминов внутри незнакомой строки.
* **paragraphs** — склеенный абзац целиком: сервер режет описания по ширине
  окна, а не по смыслу, поэтому мод склеивает строки и переносит заново.
* **priority** — меньше число, выше приоритет.
* Пустой перевод = «ещё не переведено», такие записи пропускаются.

### Перевод на другие языки

Мод не привязан к русскому — язык это папка со словарями
(`assets/skyblockru/packs/<язык>/`), а `common/` работает на любом языке,
потому что внутри `@ключи`, а не текст. Пошагово — в
**[TRANSLATING.md](TRANSLATING.md)**: что переводить, куда класть, где
грабли и какие инструменты подойдут без переделки.

### Откуда берутся тексты

| Источник | Что даёт |
|---|---|
| `api.hypixel.net` | каталог предметов, коллекции, лор аукциона **с §-кодами** |
| NotEnoughUpdates-REPO | описания предметов с цветами |
| Hypixel SkyBlock Wiki | зачарования, характеристики, локации, реплики NPC |
| сам мод | всё остальное: чат, меню, панель — пишется в `config/skyblockru/dump/` |

Инструменты сбора и проверки лежат в `tools/` — там же сторожа, которые
гоняют логику мода настоящей Java **без запуска игры** (склейка абзацев,
раскраска, резка заголовков, цели миксинов).

### Рабочий цикл

```
python tools/report.py       что сломано прямо сейчас
python tools/why.py --item "Имя предмета"   почему тут английский
python tools/refresh.py      весь круг: корпус -> перевод -> словари -> проверки -> jar
```
