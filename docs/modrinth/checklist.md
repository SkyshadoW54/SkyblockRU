**Summary (скопировать одной строкой):**

```
BETA. Russian translation for Hypixel SkyBlock: chat, item lore, menus and tooltips. Client-side, Fabric. Item names stay English on purpose. Sends untranslated interface lines to improve the translation; can be disabled.
```

⚠️ Про сбор данных сказано **прямо в Summary**. Правило Modrinth 1.11 требует
чёткого раскрытия, а не строчки в конце описания. Наш прежний текст в
`fabric.mod.json` этому правилу прямо противоречил («на сервер ничего
не отправляет») — повторять эту ошибку на витрине нельзя.

## Что грузить файлами

⚠️ **На Modrinth идут ЧИСТЫЕ jar, а не наши zip-паки.** В паках лежит ещё и
Fabric API — для прямой раздачи (Яндекс.Диск, Google Диск) это удобно, а на
площадке зависимость указывается ССЫЛКОЙ на проект Fabric API. Вложенный чужой
мод там будет лишним и вызовет вопросы у модерации.

| файл | версии игры | загрузчик |
|---|---|---|
| `skyblockru-<версия>+26.3.jar` | 26.3 | Fabric |
| `skyblockru-<версия>+26.2.jar` | 26.1, 26.1.1, 26.1.2, 26.2 | Fabric |

Оба лежат в `release/` после `python tools/release.py`. ⚠️ jar 26.2 на 26.3
не годится и наоборот: в 26.3 игра перешла с GLFW на SDL, коды клавиш разные.
1.21.11 снята 11.10.2026 — её jar на Modrinth не выкладывать.

**Зависимость:** Fabric API — `Required`.

⚠️ **Версия 0.2.0 уже роздана** релизом на GitHub. Прежде чем грузить сборку
с сегодняшними правками, поднять номер:

```bash
python tools/version.py --bump patch
```

Иначе у людей окажутся два разных мода с одинаковым номером, и ни они, ни сам
мод не смогут их различить.

**Пояснение к ИИ-контенту:**

```
The code and the Russian translations were generated by an AI model (Anthropic Claude) under my direction. I decide what is translated and what stays in English, choose the terminology, play with the mod, check translations in game and report what needs fixing. The project description was also drafted with AI. The mod does not use AI while running: translations are fixed JSON dictionaries.
```

**Телеметрия — какие данные собираются** (каждая строка — отдельный пункт):

```
Untranslated game text (item descriptions, menus, server chat messages, NPC dialogue, sidebar and tab list), used only to extend the translation
Original English text of item tooltips the player opened (item name and lines in order)
Mod version and Minecraft version
Random installation ID generated by the mod on the player's computer, not linked to the Minecraft account; used to count users (plus a short ping when joining SkyBlock, at most once every 20 hours)
Anonymous, no PII: no username, UUID, profile, other players' chat or private messages; IP addresses are not stored. Only the mod author has access. Privacy policy: https://skyblockru.duckdns.org/privacy
```

## Чего ждать при заполнении

⚠️ **Версий `26.x` может не быть в списке игровых версий Modrinth** (особенно
свежей `26.3`). Площадка добавляет версии не сразу. Если нужной нет —
загрузить пока только те сборки, чьи версии есть, а остальное выложить, когда
версии появятся. Придумывать «ближайшую похожую» версию нельзя: человек скачает
мод, который не запустится.

⚠️ **Сайт Modrinth заблокирован в РФ** с октября 2025 (отказ удалить ЛГБТК+-проекты
по требованию РКН). API и приложение работают. Значит для основной аудитории мода
Modrinth — витрина и запасной канал, а не главный способ скачать; основными
остаются GitHub Releases и прямые ссылки на диски.
