# Перевод мода на другой язык

Мод не привязан к русскому: язык — это папка со словарями. Ниже то, что нужно
знать, чтобы добавить свой, и грабли, на которых мы уже постояли.

---

## Что переводится и где лежит

| Где | Что это | Нужно переводить |
|---|---|---|
| `assets/skyblockru/packs/<язык>/*.json` | **сами переводы игры** — основная работа | да |
| `assets/skyblockru/lang/<язык>.json` | что мод пишет в чат от своего имени | да, ~40 строк |
| `assets/skyblockru/wiki/<язык>.json` | справка по терминам (Shift) | по желанию |
| `assets/skyblockru/wiki/enchants_<язык>.json` | справка по зачарованиям (Alt) | по желанию |
| `assets/skyblockru/packs/common/*.json` | работает на **любом** языке | **нет** |

`common/` не переводится потому, что внутри не текст, а `@ключи`
(`@enchantment.minecraft.protection`) — их разворачивает сам Minecraft
на языке игрока.

## Шаги

**1. Заведите папку словарей** — `assets/skyblockru/packs/<код>/`, где код
такой же, как у Minecraft: `de_de`, `pl_pl`, `uk_ua`, `zh_cn`.

**2. Впишите файлы в `packs/index.json`.**

```json
"languages": {
  "ru_ru": [ "00-glossary.json", "..." ],
  "de_de": [ "00-glossary.json" ]
}
```

⚠️ **Файл, которого нет в `index.json`, не загрузится — молча.** Содержимое
jar перечислить нельзя, поэтому список ведётся руками. Так однажды 36
зачарований не работали неделю.

**3. Проверьте `defaultLanguage` в том же файле.** Это язык, на который мод
переводит, когда под язык клиента словарей нет.

⚠️ Пока язык был один, этого поля не требовалось. С двумя языками оно
решает, что увидит игрок с английским клиентом. Раньше на его месте был
«первый по алфавиту» — то есть добавление `de_de` молча переключило бы
русских игроков на немецкий.

**4. Переведите интерфейс мода** — скопируйте `lang/en_us.json` в
`lang/<код>.json`. Чего там не окажется, Minecraft возьмёт из `en_us`,
так что мод не сломается на полпути.

**5. Соберите и проверьте.**

```bash
gradlew build
```

В игре: `/skyblockru` покажет, какой язык выбран и сколько словарей
загружено. Если словарей 0 — смотрите лог, там будет прямая жалоба
`NO DICTIONARIES for language '<код>'`.

## Формат словаря

```json
{
  "id": "мой-словарь",
  "priority": 20,
  "exact":      { "Auction House": "Аукцион" },
  "regex":      [ { "p": "^\\+([\\d,.]+) Coins$", "r": "+$1 монет" } ],
  "glossary":   { "Strength": "Сила" },
  "paragraphs": { "текст абзаца целиком": "перевод целиком" }
}
```

* `{n}` — любое число, `{s}` — ник игрока. **Их количество в переводе должно
  совпадать с оригиналом**: подстановка идёт по порядку, лишняя дырка получит
  пустоту, а переставленная — чужое число.
* `paragraphs` — склеенный абзац. Сервер режет описания по ширине окна,
  а не по смыслу, поэтому мод склеивает строки и переносит заново.
* Пустой перевод = «ещё не переведено», такая запись пропускается —
  заготовку можно класть в игру как есть.
* `priority` — меньше число, выше приоритет.

## Что стоит оставить английским

Это не про язык, а про то, как играют: **названия предметов** вводят в поиск
аукциона, **имена NPC** и **локации** называют в гайдах. Мы оставляем их
английскими даже в русской сборке. Решать вам, но учтите: переведённое
название вещи делает её ненаходимой на аукционе.

## Чего ждать от инструментов в `tools/`

Читающие инструменты (поиск, отчёты, проверки) видят словари **любого**
языка: они обходят папку целиком.

А вот **генераторы писались под русскую грамматику** и другому языку
не подойдут: `gen_rarity` перебирает род и падежи, `gen_stat_forms` строит
четыре формы характеристик, `gen_time` знает «утра» и «вечера». В них
зашито `LANG = "ru_ru"`. Это не преграда — просто такие словари для нового
языка проще собрать своими средствами, чем чинить чужие падежи.

Полезное без переделки:
* `tools/check_rules.py` — проверит, что регулярки вообще компилируются Java;
* `tools/check_translation.py` — поймает потерянные `{n}`, испорченные значки
  и смесь языков;
* `tools/find_text.py "текст"` — покажет, из какого файла взялась строка.

## Значки Hypixel

В текстах встречаются символы приватной зоны Unicode (`` и подобные) —
в шрифте Hypixel это иконки характеристик. **Их нельзя терять и нельзя
набирать руками**: из терминала они копируются как пробел. Переносите их
из оригинала как есть.
